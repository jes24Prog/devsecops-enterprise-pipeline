# Support Guide

If you encounter issues or have questions regarding the enterprise DevSecOps pipeline:

1. **Troubleshooting Matrix**: First check the comprehensive [Troubleshooting Matrix in README.md](README.md#troubleshooting) covering over 30 common issues.
2. **GitHub Discussions**: Post questions or architectural suggestions under GitHub Discussions.
3. **Issue Tracker**: Search existing issues before creating a new report.
4. **Community Discord / Chat**: Join our community chat for open-source DevSecOps support.
